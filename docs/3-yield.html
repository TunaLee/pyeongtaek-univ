Poisson 수율 모델

Y = e−A·D0Y = 수율 · A = 다이 면적 (cm²) · D0 = 결함 밀도 (개/cm²)
W07 수율Y = 90.42%
→
다이 면적A = 1 cm²
→
D0 = −ln(Y) ÷ A0.101 개/cm²
→
다른 다이 크기같은 D0 로 예상
출처 · Cunningham · IEEE TSM 3(2) 1990 · doi:10.1109/66.53188
/
3교시

Negative binomial 모델

Y = (1 + A·D0 / α)−αα = 결함이 뭉친 정도 · 작을수록 뭉침 · α 가 아주 크면 Poisson 과 같아짐
Poisson
결함웨이퍼 전체에 고르게
큰 다이수율을 낮게 봄
Negative binomial
결함한 곳에 뭉침 (클러스터)
큰 다이Poisson 보다 높게 봄
출처 · Stapper · IBM J. Res. Dev. 30(3) 1986 · doi:10.1147/rd.303.0326
