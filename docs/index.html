## 작업 규칙
- 답은 한국어로, 쉬운 말로 한다. 반도체 용어를 새로 꺼내지 않는다.
- HTML 은 파일 하나에 HTML · CSS · JS 를 모두 넣는다. 외부 라이브러리 없이 SVG 로 그린다.
- 기능을 더할 때는 이미 있는 화면을 지우지 않고 그 위에 더한다.
