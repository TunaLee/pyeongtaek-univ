Cp 와 Cpk

공정 능력 지수
Cp  = (USL − LSL) / 6σ
Cpk = min(USL − μ, μ − LSL) / 3σ

Cp  = 0.14 / 0.1348 = 1.04
Cpk = 0.0573 / 0.0674 = 0.85
